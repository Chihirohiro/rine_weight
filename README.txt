# 体重日記（個人用ウェブアプリ）

- 2021年1月26日〜2026年11月19日の体重記録を初期搭載（169件）。スクショで読み取れたコメントも含みます。
- 毎月の日記表、BMI（身長変更で全記録再計算）、グラフ（1/2/3/6か月・1/2/3年・全期間・年別）、記録した日だけ一覧、日付検索、体重とコメントの編集。
- 記録データはブラウザのlocalStorageに保存。JSONバックアップ／結合読込、CSV出力あり。
- インストール: このフォルダの `index.html` / `manifest.webmanifest` / `sw.js` / `icon-192.png` / `icon-512.png` を同じフォルダでGitHub PagesなどのHTTPS配信サービスにアップロード。iPhoneのSafariで開いて「共有」→「ホーム画面に追加」。
- ※ `index.html` を単独で開いても使えますが、オフライン動作・ホーム画面追加はHTTPS配信が必要です。ブラウザデータを消すと記録が失われるので定期的にJSONを書き出してください。
- ※ デザインは参考スクショに近づけた独自実装で、元アプリの画像やソースコードを複製したものではありません。
